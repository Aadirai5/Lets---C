# Lets---C
Let's see who survives — me or the compiler...

Day 1 — Introduction to C

    - Print Hello World.
    - Print your name, college, and branch.
    - Print a simple introduction using multiple lines.
    - Take your name or age as input and display it.


--------------------------------------------------------------------------------------

Day 2 — Variables and data types
Learn: int, float, double, char, constants, variable naming, format specifiers such as %d, %f, %c, %lf.

    - Store and print a student's details.
    - Calculate the sum and average of three numbers.
    - Convert Celsius to Fahrenheit.
    - Calculate the area of a circle.

--------------------------------------------------------------------------------------

Day 3 — Operators
Learn: Arithmetic, relational, logical, assignment, increment/decrement, conditional (?:), and type casting.

    - Build a two-number calculator
    .Swap two numbers using a temporary variable.
    - Calculate quotient and remainder.
    - Find the largest of two numbers using the conditional operator.

------------------------------------------------------------------------------------------

Day 4 — If, else and switch
Learn: if, else if, nested conditions, switch, break, and logical conditions.

    - Check whether a number is positive, negative, or zero.
    - Check even or odd.
    - Find the largest of thre
    e numbers.
    -Create a calculator using switch.
    - Make a grade calculator based on marks.


------------------------------------------------------------------------------------------------------

Day 5 — Loops
Learn: for, while, do-while, break, continue, nested loops.

    - Print numbers from 1 to 100.
    - Print the multiplication table of any number.
    - Find the sum of the first N natural numbers.
    - Print all even numbers between 1 and 100.
    - Reverse a number using a loop.

--------------------------------------------------------------------------------------


Day 6 — Number logic
Learn: Digits, remainders, divisibility, nested loops, basic mathematical algorithms.

    - Check whether a number is prime.
    - Find the factorial of a number.
    - Check whether a number is a palindrome.
    - Find the sum of digits.
    - Check whether a number is an Armstrong number.


---------------------------------------------------------------------------------------------

Day 7 — Patterns and revision
Learn: Nested-loop logic, rows, columns, and pattern construction.

    - Print a square of stars.
    - Print a right-angled triangle.
    - Print an inverted triangle.
    - Print a pyramid.
    - Print a number triangle.
    
---------------------------------------------------------------------------------------------------------

Day 8 — Functions
Learn: Function declaration, definition, function call, parameters, return values, local and global variables, scope, storage classes (auto, static, extern, register).

     Create functions for addition and multiplication.
      Make a function to check prime numbers.
     Find the maximum of three numbers using a function.
     Make a menu-driven calculator using functions.

---------------------------------------------------------------------------------------

Day 9 — One-dimensional arrays
Learn: Array declaration, initialization, indexing, traversal, updating elements.

    
    Input and print 10 numbers.
    Find the maximum and minimum element.
    Calculate the sum and average of an array.
    Reverse an array.
    Count even and odd elements.

---------------------------------------------------------------------

Day 10 — Two-dimensional arrays
Learn: Matrices, nested loops, rows and columns.


     Add two matrices.
     Subtract two matrices.
     Find the transpose of a matrix.
     Calculate diagonal sums.
     Multiply two matrices.

---------------------------------------------------------------------

Day 11 — Strings
Learn: Character arrays, null terminator '\0', fgets(), puts(), and functions from <string.h>.

Practice:
-     Find string length without strlen().
-     Reverse a string without a built-in reverse function.
-     Check whether a string is a palindrome.
-     Count vowels, consonants, digits, and spaces.
-     Compare two strings.

--------------------------------------------------------------------------------

Day 12 — Searching and sorting
Learn: Linear search, binary search, bubble sort, selection sort, insertion sort, time complexity basics.

Practice:
-     Search for an element in an array.
-      Implement binary search on a sorted array.
-     Sort numbers in ascending and descending order.
-     Find the second-largest element.
-     Remove duplicate values from an array.

-----------------------------------------------------------------

Day 13 — Recursion
Learn: Base case, recursive case, call stack, recursion versus iteration.

-     Calculate factorial recursively.
-     Print the Fibonacci sequence.
-     Find the sum of digits recursively.
-     Find the power of a number.
-     Solve Tower of Hanoi.

---------------------------------------------------------------------


Day 14 — Week 2 revision challenge

-     Build a student marks management program using arrays and functions.
-     Search for a student's marks.
-     Sort students' marks.
-     Find the class average and highest score.
