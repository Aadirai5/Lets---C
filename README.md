# Lets---C
Let's see who survives — me or the compiler...

Day 1 — Introduction to C

    - Print Hello World.
    - Print your name, college, and branch.
    - Print a simple introduction using multiple lines.
    - Take your name or age as input and display it.


--------------------------------------------------------------------------------------

Day 2 — Variables and data types
Learn: int, float, double, char, constants, variable naming, format specifiers such as %d, %f, %c, %lf.

    - Store and print a student's details.
    - Calculate the sum and average of three numbers.
    - Convert Celsius to Fahrenheit.
    - Calculate the area of a circle.

--------------------------------------------------------------------------------------

Day 3 — Operators
Learn: Arithmetic, relational, logical, assignment, increment/decrement, conditional (?:), and type casting.

    - Build a two-number calculator
    .Swap two numbers using a temporary variable.
    - Calculate quotient and remainder.
    - Find the largest of two numbers using the conditional operator.

------------------------------------------------------------------------------------------

Day 4 — If, else and switch
Learn: if, else if, nested conditions, switch, break, and logical conditions.

    - Check whether a number is positive, negative, or zero.
    - Check even or odd.
    - Find the largest of thre
    e numbers.
    -Create a calculator using switch.
    - Make a grade calculator based on marks.


------------------------------------------------------------------------------------------------------

Day 5 — Loops
Learn: for, while, do-while, break, continue, nested loops.

    - Print numbers from 1 to 100.
    - Print the multiplication table of any number.
    - Find the sum of the first N natural numbers.
    - Print all even numbers between 1 and 100.
    - Reverse a number using a loop.

--------------------------------------------------------------------------------------


Day 6 — Number logic
Learn: Digits, remainders, divisibility, nested loops, basic mathematical algorithms.

    - Check whether a number is prime.
    - Find the factorial of a number.
    - Check whether a number is a palindrome.
    - Find the sum of digits.
    - Check whether a number is an Armstrong number.


---------------------------------------------------------------------------------------------

Day 7 — Patterns and revision
Learn: Nested-loop logic, rows, columns, and pattern construction.

    - Print a square of stars.
    - Print a right-angled triangle.
    - Print an inverted triangle.
    - Print a pyramid.
    - Print a number triangle.
